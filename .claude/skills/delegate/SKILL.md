# 分身に振る(サブエージェント分割 + 独立検証)

Claude 1体で直列にやるのが上限ではない。独立した作業はサブエージェントに分けて並列で走らせ、本体はリーダーとして統合に専念する。

## 手順

1. **分割**: タスクを「互いの結果に依存しない単位」に分ける。依存があるものは同じエージェントにまとめるか、順番に流す。
2. **並列起動**: 独立した単位は Agent ツールで**1つのメッセージから同時に**起動する(直列に待たない)。各エージェントへの指示には以下を必ず含める:
   - 目的(なぜこの作業をするのか)
   - 担当範囲と、**触ってはいけない範囲**
   - 期待する成果物の形式(返すべき情報を具体的に)
3. **本体は止まらない**: サブが走っている間、本体は自分にしかできない作業(設計判断・統合準備)を続ける。
4. **まっさらな分身に検証させる**: 全作業の完了後、実装に関わっていない**新規の**エージェントを1体起動し、成果物だけを渡して検証させる。検証エージェントには「粗探しをする側」として指示する:
   - 要件と成果物を照合し、漏れ・矛盾・壊れている箇所を報告させる
   - 実装時の思い込みを引き継がせない(実装の経緯や言い訳を渡さない)
5. **検証結果を反映**: 指摘が正しければ修正し、修正後に再検証。問題なしになってから完了報告する。

## 注意

- 並列でファイルを書き換えるエージェント同士が同じファイルに触る場合は、worktree 分離を使うか、分割を見直す
- サブエージェントの報告は鵜呑みにしない(CLAUDE.md の「報告の前に実行結果と照合」はサブの報告にも適用する)
- 小さすぎるタスクを分割するオーバーヘッドは無駄。1体で数分で終わるものはそのままやる
