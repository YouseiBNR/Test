## 共通プロンプト補足

### スタイル強化オプション（必要に応じて追記）
```

```

### Vidu Q3 設定推奨値
| 項目 | 推奨値 |
|------|--------|
| アスペクト比 | 9:16 |
| 動画長 | 4〜8秒（ループ or 連結） |
| モーション強度 | Medium (中程度) |
| スタイル | Anime / Illustration |
| シード値 | 同一キャラは同シードで統一推奨 |

### 制作フロー
1. Vidu Q3 でキャラ動画を生成（本プロンプト使用）
2. Sjinn エージェントで音声・BGM・テロップを合成
3. 台本は `lifehack-scripts.md` を参照
4. 各プラットフォーム向けに最終書き出し
